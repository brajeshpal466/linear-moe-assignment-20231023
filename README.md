# Linear MoE Assignment

This repository contains a demonstration of training a simple linear regression model and converting it into a Mixture‑of‑Experts (MoE) model using PyTorch.

## Files
- `train_linear_moe.py`
- `requirements.txt`
- `training_log.txt`

## How to Run
```bash
pip install -r requirements.txt
python train_linear_moe.py
```
